# 작업 목적

- `system_monitor.ps1`을 실행해 시스템 정보를 조회하고 화면 출력 결과를 확인한다.

# 실행 파일과 실행 명령

- 실행 파일: `C:\ai-starter\system-monitor\system_monitor.ps1`
- 실행 명령:

```powershell
powershell.exe -ExecutionPolicy Bypass -File "C:\ai-starter\system-monitor\system_monitor.ps1"
```

# 작업 순서

- 파일 확인: `system_monitor.ps1`이 지정된 경로에 있는지 확인한다.
- 실행: 위 실행 명령으로 스크립트를 실행한다.
- 결과 확인: 화면에 출력된 시스템 정보가 정상적으로 표시되는지 확인한다.
- 완료 보고: 실행 여부와 확인한 결과를 사용자에게 짧게 보고한다.

# 작업 제한

- 파일을 수정하지 않는다.
- 프로그램이나 패키지를 설치하지 않는다.
- 시스템 설정을 변경하지 않는다.
- 요청된 스크립트 실행과 결과 확인만 수행한다.

# 오류 처리

- 오류가 발생하면 임의로 파일을 수정하지 않는다.
- 오류 내용을 먼저 사용자에게 보고한다.
- 원인 추정이 가능하면 짧게 함께 설명한다.

# 완료 조건

- `system_monitor.ps1` 실행이 완료된다.
- 출력된 시스템 정보 결과를 확인한다.
- 실행 결과를 사용자에게 보고한다.
